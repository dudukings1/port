# Portfolio — Eduardo Dutra Rosolen

Site pessoal em página única, construído com React 19 + TypeScript + Vite e animações com Framer Motion.

## Stack

- React 19 + TypeScript + Vite
- Framer Motion (animações de scroll)
- react-icons

## Rodando localmente

```bash
npm install
npm run dev
```

## Deploy

Deploy automático na Vercel a cada push na branch principal.
